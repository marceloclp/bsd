## Fixed and length-prefixed arrays

Pass a static element count or a `BsdSchema<number>` to `array()`. A dynamic
count is consumed from the input and omitted from the result.

```ts
import { array, u8, u16 } from "@marceloclp/eke";

const coordinates = array(3, u16());
coordinates.decode(Uint8Array.of(10, 0, 20, 0, 30, 0));
// [10, 20, 30]

const counted = array(u8(), u16());
counted.decode(Uint8Array.of(2, 10, 0, 20, 0));
// [10, 20]
```

Each element's zero-based index is added to the reader path while it decodes.
Counts must be nonnegative safe integers.

## Repeat to a boundary

`repeat(schema)` decodes elements until the active frame boundary. At the top
level, that boundary is the end of the input.

```ts
import { repeat, u16 } from "@marceloclp/eke";

repeat(u16()).decode(Uint8Array.of(1, 0, 2, 0, 3, 0));
// [1, 2, 3]
```

The element schema must advance the cursor on every iteration; a zero-width
element is rejected to prevent an infinite loop.

## Exact frames

`frame(byteLength, schema)` gives a child schema its own exact boundary. The
child cannot read past that boundary and must consume it completely.

```ts
import { frame, repeat, struct, u8, u16 } from "@marceloclp/eke";

const block = frame(
    5,
    struct({
        kind: u8(),
        values: repeat(u16()),
    }),
);
```

The byte length may also be calculated from the current `BsdReader`. It is
relative to the current cursor.

```ts
const restOfParentFrame = frame((reader) => reader.remaining, repeat(u16()));
```

## Value-dependent layouts

Use `flatMap()` when a decoded value selects the schema for the following
bytes. The controlling value is consumed but is not included in the result.

```ts
import { bytes, u8, u16 } from "@marceloclp/eke";

const payload = u8().flatMap((kind) => (kind === 1 ? bytes(4) : bytes(u16())));
```

Use `defer()` when the choice must happen before consuming a controlling value.
The callback can inspect the reader or use non-consuming lookahead.

```ts
import { defer, u8, u16 } from "@marceloclp/eke";

const taggedInteger = defer((reader) =>
    reader.uint(8, { advance: false }) === 1 ? u8() : u16(),
);
```

Dynamic `frame()` and `defer()` resolvers must leave reader state unchanged.
Use raw reads with `{ advance: false }` or `reader.peek(schema)` for lookahead;
Eke restores and rejects a resolver that mutates the cursor, frame, or path.

## Alternatives and zero-width values

`union()` tries schemas in order. A branch that throws `DecodeError` restores
the reader state before the next branch runs. Other exceptions propagate.

`constant(value)` produces a typed value without consuming bytes. `offset()`
produces the current absolute cursor in the same way. These are useful in
structs and transforms, but a `repeat()` element must still consume bytes.
