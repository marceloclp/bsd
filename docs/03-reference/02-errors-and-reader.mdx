## `DecodeError`

Binary input failures throw `DecodeError`. It keeps machine-readable context
separate from its formatted message.

| Property  | Type                     | Meaning                                    |
| --------- | ------------------------ | ------------------------------------------ |
| `name`    | `"DecodeError"`          | Stable public error name                   |
| `offset`  | `number`                 | Starting byte offset of the failing schema |
| `path`    | `readonly PropertyKey[]` | Nested field and array path                |
| `cause`   | `unknown`                | Optional original error                    |
| `message` | `string`                 | Human-readable context and issue text      |

The path is copied when an error is created, so later reader mutations cannot
change an existing error.

The constructor accepts an issue string and exported `DecodeErrorOptions`:

```ts
interface DecodeErrorOptions {
    offset: number;
    path: readonly BsdPathSegment[];
    cause?: unknown;
}
```

```ts
import { DecodeError, array, u8 } from "@marceloclp/eke";

try {
    array(3, u8().lt(10)).decode(Uint8Array.of(1, 2, 99));
} catch (error) {
    if (error instanceof DecodeError) {
        console.error(error.offset); // 2
        console.error(error.path); // [2]
        console.error(error.message);
    }
}
```

Exceptions thrown by application callbacks are not interpreted as alternate
`union()` branches. Only `DecodeError` represents a recoverable decode failure.

## `BsdReader`

`BsdReader` is the public decoder and mutable state shared by composed schemas.
It is passed to `custom()`, `defer()`, `check()`, `transform()`, `flatMap()`, and
dynamic `frame()` callbacks.

Construct one directly with `new BsdReader(buffer: Uint8Array)` when using the
low-level API outside a top-level schema.

| Property    |     Mutability      | Purpose                                    |
| ----------- | :-----------------: | ------------------------------------------ |
| `buffer`    | Read-only reference | Original input `Uint8Array`                |
| `view`      | Read-only reference | `DataView` scoped to the exact input range |
| `path`      |       Mutable       | Current struct keys and array indexes      |
| `position`  |       Mutable       | Starting offset of the current schema      |
| `offset`    |       Mutable       | Current absolute cursor                    |
| `limit`     |       Mutable       | Exclusive boundary of the active frame     |
| `remaining` |       Getter        | `limit - offset`                           |

This state is deliberately exposed. A specialized decoder may inspect or
update it directly, provided it preserves the invariants expected by its
surrounding schemas: offsets and limits are safe integers, `0 <= offset <=
limit <= buffer.length`, and any temporary path or frame changes are restored.

## Schema reads

```ts
reader.read<S extends BsdAny>(schema: S): Infer<S>;
reader.peek<S extends BsdAny>(schema: S): Infer<S>;
reader.fail(message: string, options?: { cause?: unknown }): never;
```

`peek()` restores the cursor, active limit, member position, and path whether
the schema succeeds or fails.

## Raw reads

The low-level methods consume bytes from `offset` and respect `limit`. Pass
`{ advance: false }` for non-consuming lookahead.

The package exports `BsdIntegerBits`, `BsdBigIntegerBits`, `BsdFloatBits`, and
`BsdReadOptions` for code that wraps these methods.

```ts
type BsdIntegerBits = 8 | 16 | 24 | 32;
type BsdBigIntegerBits = 64;
type BsdFloatBits = 32 | 64;
interface BsdReadOptions {
    advance?: boolean;
}
```

```ts
reader.uint(bits: BsdIntegerBits, options?: BsdReadOptions): number;
reader.int(bits: BsdIntegerBits, options?: BsdReadOptions): number;
reader.biguint(bits: BsdBigIntegerBits, options?: BsdReadOptions): bigint;
reader.bigint(bits: BsdBigIntegerBits, options?: BsdReadOptions): bigint;
reader.float(bits: BsdFloatBits, options?: BsdReadOptions): number;

reader.bytes(byteLength: number, options?: BsdReadOptions): Uint8Array;
reader.ascii(byteLength: number, options?: BsdReadOptions): string;
reader.latin1(byteLength: number, options?: BsdReadOptions): string;
reader.utf8(byteLength: number, options?: BsdReadOptions): string;
reader.utf16le(byteLength: number, options?: BsdReadOptions): string;
```

Numeric methods are little-endian. `bytes()` returns a zero-copy view. `ascii()`
rejects bytes above `0x7f`; `latin1()` preserves every byte; `utf8()` uses fatal
decoding and rejects malformed input; and `utf16le()` requires an even byte
count.

## Custom schemas

Use `custom()` when a layout is clearer as direct cursor operations than as a
combination of built-in schemas.

```ts
import { custom } from "@marceloclp/eke";

const packedNibble = custom((reader) => {
    const value = reader.uint(8);
    return {
        high: value >>> 4,
        low: value & 0x0f,
    };
});
```

Use `reader.fail()` for invalid input so the failure carries the active offset
and path.

```ts
const signature = custom((reader) => {
    const value = reader.uint(16);
    if (value !== 0x4b45) reader.fail("invalid signature");
    return value;
});
```
