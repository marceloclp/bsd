Schema methods are immutable. Each method returns a schema with the additional
behavior while the original remains reusable.

## Equality and membership

`is()` validates `Object.is` equality. `oneOf()` validates membership in a
non-empty list using the same comparison. Both narrow the inferred TypeScript
result; notably, `NaN` matches itself and `0` differs from `-0`.

```ts
import { u8 } from "@marceloclp/eke";
import type { Infer } from "@marceloclp/eke";

const marker = u8().is(0x7f);
const status = u8().oneOf(0, 1, 2);

type Marker = Infer<typeof marker>; // 0x7f
type Status = Infer<typeof status>; // 0 | 1 | 2
```

## Custom checks

`check()` receives the decoded value and active `BsdReader`. Return `false` to
reject the value, return nothing to accept it, or call `reader.fail()` with a
specific message.

```ts
import { u16 } from "@marceloclp/eke";

const even = u16().check((value, reader) => {
    if (value % 2 !== 0) {
        reader.fail("expected an even value");
    }
});
```

Multiple checks may be supplied in one call and run in declaration order.

```ts
const smallEven = u16().check(
    (value) => value <= 100,
    (value) => value % 2 === 0,
);
```

## Transform values

`transform()` maps a decoded value to a new result and returns the specialized
schema interface appropriate for that result.

```ts
import { u16 } from "@marceloclp/eke";

const flags = u16().transform((value) => ({
    readable: (value & 0b001) !== 0,
    writable: (value & 0b010) !== 0,
}));
```

`flatMap()` instead uses the decoded value to select and consume the following
schema. Use it for tagged unions and sizes encoded before their payload.

```ts
import { bytes, u16 } from "@marceloclp/eke";

const sizedPayload = u16().flatMap((byteLength) => bytes(byteLength));
```

## Skip and peek

`skip(byteLength)` advances over arbitrary bytes after decoding a value and
retains that value as the result.

```ts
import { struct, u8 } from "@marceloclp/eke";

const header = struct({
    id: u8().skip(3),
    code: u8(),
});
```

`peek()` decodes a schema and restores the reader's cursor, frame, position,
and path afterward, including when decoding fails. It is useful when the same
bytes contribute to more than one field.

```ts
const flagsAndRaw = struct({
    lowBits: u8()
        .peek()
        .transform((value) => value & 0x0f),
    raw: u8(),
});
```

At the reader level, `reader.peek(schema)` provides the same non-consuming
behavior inside `custom()`, `defer()`, checks, and transforms.

## Select fields

`BsdStruct.pick(...keys)` and `BsdStruct.omit(...keys)` return new decoded
objects and preserve exact property types.

```ts
const publicHeader = header.pick("id");
const withoutCode = header.omit("code");
```
