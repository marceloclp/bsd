<Steps>
  <Step title="Install Eke">
    ```bash
    bun add @marceloclp/eke
    ```

    Eke is an ESM package and ships its TypeScript declarations with the
    JavaScript build.

  </Step>
  <Step title="Create a schema">
    ```ts
    import { array, struct, u8, u16 } from "@marceloclp/eke";
    import type { Infer } from "@marceloclp/eke";

    const packet = struct({
      version: u8().is(1),
      samples: array(u8(), u16()),
    });

    type Packet = Infer<typeof packet>;
    ```

  </Step>
  <Step title="Decode bytes">
    ```ts
    const decoded: Packet = packet.decode(
      Uint8Array.of(1, 2, 10, 0, 20, 0),
    );

    console.log(decoded);
    // { version: 1, samples: [10, 20] }
    ```

  </Step>
</Steps>

## Complete-input decoding

Calling `decode()` creates a `BsdReader`, decodes the schema, and verifies that
the final cursor equals the input boundary.

```ts
import { u8 } from "@marceloclp/eke";

u8().decode(Uint8Array.of(7)); // 7
u8().decode(Uint8Array.of(7, 8)); // throws: trailing byte
u8().decode(Uint8Array.of()); // throws: out of bounds
```

Nested schemas are checked against their active `frame()` boundary. The outer
`decode()` still enforces complete consumption of the whole input.

## Handle contextual errors

```ts
import { DecodeError, array, u8 } from "@marceloclp/eke";

try {
    array(3, u8().lte(10)).decode(Uint8Array.of(1, 99, 3));
} catch (error) {
    if (error instanceof DecodeError) {
        console.error(error.offset); // 1
        console.error(error.path); // [1]
        console.error(error.message);
    }
}
```

## Transform into application types

`transform()` changes both the decoded result and its inferred type.

```ts
import { u16 } from "@marceloclp/eke";

const flags = u16().transform((value) => ({
    readable: (value & 0b001) !== 0,
    writable: (value & 0b010) !== 0,
    executable: (value & 0b100) !== 0,
}));

flags.decode(Uint8Array.of(0b011, 0));
// { readable: true, writable: true, executable: false }
```
