Every built-in numeric schema reads little-endian data and returns a
`BsdNumber` with chainable numeric checks.

## Integers

| Schema  |   Width | Signed | Result   |
| ------- | ------: | :----: | -------- |
| `u8()`  |  1 byte |   No   | `number` |
| `u16()` | 2 bytes |   No   | `number` |
| `u24()` | 3 bytes |   No   | `number` |
| `u32()` | 4 bytes |   No   | `number` |
| `u64()` | 8 bytes |   No   | `bigint` |
| `i8()`  |  1 byte |  Yes   | `number` |
| `i16()` | 2 bytes |  Yes   | `number` |
| `i24()` | 3 bytes |  Yes   | `number` |
| `i32()` | 4 bytes |  Yes   | `number` |
| `i64()` | 8 bytes |  Yes   | `bigint` |

```ts
import { i16, u24, u64 } from "@marceloclp/eke";

i16().decode(Uint8Array.of(0xfe, 0xff));
// -2

u24().decode(Uint8Array.of(0x56, 0x34, 0x12));
// 0x123456

u64().decode(Uint8Array.of(8, 7, 6, 5, 4, 3, 2, 1));
// 0x0102030405060708n
```

:::warning
`u64()` and `i64()` return `bigint`. Use bigint literals in their checks, such
as `u64().gt(0n)`.
:::

## Floating point

`f32()` and `f64()` decode little-endian IEEE-754 values and return `number`.

```ts
import { f32 } from "@marceloclp/eke";

const input = new Uint8Array(4);
new DataView(input.buffer).setFloat32(0, 1.5, true);

f32().decode(input); // 1.5
```

## Numeric validation

`BsdNumber` adds `gt()`, `gte()`, `lt()`, `lte()`, `positive()`, and
`negative()`. Checks are immutable: each call creates a new schema and leaves
the original reusable.

```ts
import { i32, u16 } from "@marceloclp/eke";

const anyPort = u16();
const tcpPort = anyPort.gte(1).lte(65_535);
const belowSeaLevel = i32().negative();
```

A failed numeric check throws `DecodeError` at the number's starting offset and
current path.

## Literal narrowing

All schema types support `is()` and `oneOf()`. Besides validating at runtime,
they narrow the inferred result to the supplied literal values. Both use
`Object.is` equality, so `NaN` matches itself and `0` differs from `-0`.

```ts
import { u8 } from "@marceloclp/eke";
import type { Infer } from "@marceloclp/eke";

const version = u8().is(2);
type Version = Infer<typeof version>; // 2

const status = u8().oneOf(0, 1, 3);
type Status = Infer<typeof status>; // 0 | 1 | 3
```
